# Contributing to Awesome DevOps Freelance

First off, thank you for considering contributing! This project aims to be the most comprehensive curated DevOps freelance resource → and that only works with community help.

## How to Contribute

### 🛠 Adding a Tool
1. Check the tool isn't already listed
2. Verify it meets standards:
   - 500+ GitHub stars **OR** CNCF project **OR** commercially proven
   - Relevant to DevOps freelancers
   - Active development or maintenance
3. Open an issue or PR with:
   - Tool name and URL
   - Category
   - Brief description (2-3 sentences)
   - Why it matters for freelancers
   - Source for any claims (GitHub stars, pricing, etc.)

### 📝 Updating a Resource
- Found a broken link? Open a PR
- Rate data outdated? Open an issue with new data + source
- New paradigm emerging? Suggest a new category

### 🔬 Academic References
- Have a relevant SLR or paper? Open a PR adding it to `docs/paradigms/academic-references.md`
- Include: full citation, DOI/arXiv ID, and 2-3 sentence summary of findings

### 💼 Freelancer Insights
- Have data on freelance rates or patterns? Open an issue
- See a pattern we missed? Share your analysis

## Quality Standards

- **No AI-generated content without verification**: All claims must trace to a real source
- **No affiliate links without disclosure**: Be transparent about commercial relationships
- **No spam or self-promotion**: Tools should be genuinely useful, not marketing
- **No opinion without evidence**: "This is good" needs backing

## Before Submitting

- [ ] Check the existing content for duplicates
- [ ] Verify all URLs are working
- [ ] Include sources for factual claims
- [ ] Use consistent formatting (see existing entries)

## Questions?

Open an issue with the `question` label. We're happy to help!
